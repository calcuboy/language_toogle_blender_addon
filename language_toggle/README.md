# Quick Language Toggle — Blender 界面语言快捷切换插件

用一组自定义快捷键，在任何编辑器窗口里**瞬间**在中文和英文界面之间来回切换，不用再翻 `Preferences > Interface > Language`，也不用重启 Blender。

---

## 安装

**先看你的 Blender 版本：**

| Blender 版本 | 用哪个包 | 说明 |
| --- | --- | --- |
| **4.2 及以上**（含 5.x） | `dist/language_toggle-1.0.0-ext.zip` | 扩展包（extension）格式，顶层是 `blender_manifest.toml` |
| 2.80 – 4.1 | `dist/language_toggle-1.0.0.zip` | 传统插件格式，顶层是 `language_toggle/` 文件夹 |

**5.0 开始 Blender 已移除传统插件支持**，所以 5.x 必须用 `-ext` 那个。

安装步骤（以 5.x 为例）：

1. `编辑 > 偏好设置 > 获取扩展（Get Extensions）`。
2. 右上角下拉菜单 → **从磁盘安装（Install from Disk…）**。
3. 选择 `language_toggle-1.0.0-ext.zip`，不要解压。
4. 切到 `插件（Add-ons）`，搜索 **Quick Language Toggle**，勾选启用。

启用后不需要重启，快捷键立即生效。

## 使用

按下默认快捷键 **`Ctrl + Alt + L`** —— 界面立刻在中英之间翻转。

也能在 `编辑（Edit）` 菜单的最下面找到 **Toggle Interface Language**，鼠标党不用记快捷键。

## 配置

`偏好设置 > 插件 > Quick Language Toggle` 展开后有三块：

### 1. 切换方式（Switching Mode）

| 模式 | 作用 | 适合谁 |
| --- | --- | --- |
| **界面翻译开关**（默认） | 只翻转 `翻译界面` 这个开关，语言设置本身不动。效果是「英文 ↔ 你选的那个语言」。 | 大多数人。不污染语言设置，工具提示、新建数据名可跟随联动。 |
| **切换语言** | 直接改语言本身，在 语言 A / 语言 B 之间往返。 | 需要在两种外语之间切换，或者希望连 `偏好设置` 里的选项文字一起变。 |

两种模式都可以勾选：

- **同时切换工具提示** —— 按钮悬停提示的翻译跟着一起开关。
- **同时切换新建数据名** —— 新建物体 / 材质时自动加中缀的行为跟着一起开关。

> 这三项其实就是 Blender `偏好设置 > 界面` 里那三个 `翻译` 复选框，插件只是把它们绑到了一个键上。

### 2. 快捷键（Shortcut）

点显示当前快捷键的那个按钮（默认 `Ctrl + Alt + L`）→ 按钮变成 `Listening…` → 直接按下你想要的组合键。

- 按住修饰键（Ctrl / Shift / Alt / Win）再按主键，**整组组合键一次录完**，不用分开设。
- 想取消就按 `Esc`。
- 勾掉 **启用全局快捷键** 可以彻底停用快捷键，只留菜单项。

快捷键注册在 Blender 的 `Window` 键位映射里，所以**任何窗口**（3D 视图、节点编辑器、UV、偏好设置，甚至弹出的文件浏览器）里都能触发。

### 3. 其它

- **切换后保存偏好设置** —— 默认关闭。打开后每次切换都会写一次 `userpref.blend`，重启后保持你最后的状态。

## 关于「界面翻译开关」和「切换语言」的区别

Blender 的语言逻辑是两层：

1. `语言`（language）决定用哪套翻译字典，比如 `zh_HANS`。
2. `翻译界面`（Translate Interface）决定这套字典**要不要用**。

所以当语言是「简体中文」时，把 `翻译界面` 关掉，界面就是英文；再打开，又是中文。**语言设置没变，只是用了哪个字典的问题**——这也是网上流传的那个 `context.toggle` + `preferences.view.use_translate_interface` 手动键位做法的原理，本插件把它规范化成了一个可配置的附加组件。

「切换语言」模式则直接改第 1 层，更彻底，但会真的改掉你的语言偏好。

## 注意事项 / FAQ

**Q: 按了没反应？**
检查偏好设置里快捷键是否显示为红色（冲突），或换一组组合，比如 `Ctrl+Alt+J`。某些输入法会拦截 `Ctrl+Alt+字母`，遇到就把输入法切到英文状态，或改用 `Shift+Alt+字母`。

**Q: 为什么个别文字没变？**
Blender 的界面重绘是分区域的，插件已经对全部编辑器调用了 `tag_redraw` 并强制做了一次 `DRAW_WIN_SWAP`。仍有极少数已打开的弹窗 / 折叠面板需要重开一次才会刷新——这是 Blender 自身的限制，任何改语言的插件都一样。

**Q: 能用 `Alt + Win` 吗？**
可以录进去，但 Windows 系统会优先截获 `Win` 键（弹出开始菜单），实际很难触发，不建议。macOS 上是 `Cmd`，同样容易被系统吃掉。**推荐 `Ctrl+Alt+L` 或 `Ctrl+Shift+Alt+L` 这类纯修饰键组合。**

**Q: 卸载后会留残余吗？**
不会。禁用插件时会自动移除注册的快捷键和翻译字典。

## 目录结构

```
language_toggle/
├── blender_manifest.toml  # 扩展包清单（4.2+ / 5.x 用）
├── __init__.py            # bl_info / 注册卸载 / Edit 菜单入口
├── props.py               # AddonPreferences：配置项、语言表与面板绘制
├── operators.py           # 切换操作符 + 快捷键录制（模态）
├── keymap.py              # Window 键位映射注册与重建
├── utils.py               # 重绘、快捷键文字格式化
└── i18n.py                # 插件自身的中英双语
```

- `界面翻译开关` 模式：`翻译界面 / 工具提示 / 新建数据名` 三个开关正确联动翻转；

- 快捷键注册为 `Window` 键位映射中的 `L + Ctrl + Alt`，禁用插件时自动清除；

- 中英双语在切换语言后生效。

其它版本：

## 自测（改完代码后）

> 仅限本源码仓库，直接拿 zip 安装的用户可以忽略这一节。

项目根目录的 `tools/verify_in_blender.py` 会把 `dist` 里的扩展包装进临时目录并跑 12 项断言
（安装、两种模式翻转、键位注册、翻译、禁用清理），**不会污染你真实的 Blender 配置**：

```bash
"D:/blender-5.2.1-windows-x64/blender.exe" -b --factory-startup \
    --python tools/verify_in_blender.py
```

看到 `ALL CHECKS PASSED` 就说明没写坏。
